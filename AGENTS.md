# Project instructions

Read and follow `.codex/development.md` for development in this repository.
For changes to application behavior or tests, also follow `.codex/testing.md`.
For PHP, Composer, Artisan, or formatting commands, use `.codex/runtime.md`.

These rules derive from `AI stats task specification/base-spec.md` and the
existing code. Explicit task requirements and the base specification take
precedence over inferred conventions. Read the relevant source and tests before
changing a feature; do not treat existing defects or incomplete tests as requirements.
